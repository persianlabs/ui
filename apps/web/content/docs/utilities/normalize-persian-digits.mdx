import { normalizePersianDigitsApi } from "@/lib/api-data/normalize-persian-digits"

Persian keyboards commonly type ۰-۹ (or Arabic-Indic ٠-٩) instead of 0-9. This utility converts either set back to plain digits, so numeric inputs and parsers keep working regardless of which keyboard the user is on. [Price Input](/docs/components/price-input) uses it internally.

## Usage

```tsx
import { normalizePersianDigits } from "@/lib/normalize-persian-digits"

normalizePersianDigits("۱۲۳۴۵") // "12345"
normalizePersianDigits("قیمت ٤٥٠") // "قیمت 450"
```
