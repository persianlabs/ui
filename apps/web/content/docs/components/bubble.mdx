## Usage

```tsx
import { Bubble, BubbleContent, BubbleGroup } from "@/components/ui/bubble"

export function Example() {
  return (
    <BubbleGroup>
      <Bubble align="start" variant="muted">
        <BubbleContent>Hey, do you have a minute?</BubbleContent>
      </Bubble>
      <Bubble align="end">
        <BubbleContent>Sure, what's up?</BubbleContent>
      </Bubble>
    </BubbleGroup>
  )
}
```

### Variants

<ComponentPreview name="bubble-variants" />

### Alignment

Use `align` on `Bubble` to align the bubble to the start or end of the conversation.

<ComponentPreview name="bubble-alignment" />

### Bubble Group

Use `BubbleGroup` to group consecutive bubbles from the same sender. Set `align` on each `Bubble`, not on the group.

<ComponentPreview name="bubble-group" />

### Links and Buttons

Turn a bubble into a link or button with the `render` prop on `BubbleContent`.

<ComponentPreview name="bubble-link-button" />

### Reactions

Use `BubbleReactions` for reactions or quick action buttons. Use `side` and `align` to position the row.

<ComponentPreview name="bubble-reactions" />

### Show More / Collapsible

Long bubble content can be composed with [Collapsible](/docs/components/collapsible) for a show more / show less interaction.

<ComponentPreview name="bubble-collapsible" />

### Tooltip

Wrap a reaction in [Tooltip](/docs/components/tooltip) to reveal metadata on hover, such as a read receipt.

<ComponentPreview name="bubble-tooltip" />

### Popover

Pair a bubble with a [Popover](/docs/components/popover) to surface more information on demand, such as a full error message.

<ComponentPreview name="bubble-popover" />

### RTL

`align="end"` correctly sits on the visual left under RTL, and reactions mirror along with it, so a chat thread reads naturally either way.

<ComponentPreview name="bubble-rtl" direction="rtl" />
