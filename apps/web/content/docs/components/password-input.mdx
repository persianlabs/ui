import { passwordInputApi } from "@/lib/api-data/password-input"

A single-field password input built on [Input Group](/docs/components/input-group), with a show/hide toggle. Passwords are opaque strings, not RTL-meaningful text, so the field forces `dir="ltr"` and keeps the toggle button on the same physical side, regardless of the surrounding document direction.
