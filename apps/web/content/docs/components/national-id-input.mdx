A plain Iranian national ID (کد ملی) field built on [Input Group](/docs/components/input-group), validated through the [National ID](/docs/utilities/national-id) utility. It normalizes Persian and Arabic-Indic digits to Latin as you type or paste, using [Normalize Persian Digits](/docs/utilities/normalize-persian-digits), caps the value at 10 digits, and shows a shape-based (not color-only) checkmark or alert icon once the value looks complete.

## Usage

```tsx
import { NationalIdInput } from "@/components/ui/national-id-input"

export function Example() {
  return <NationalIdInput />
}
```

The value is the typed digits only — Latin `0`–`9`, at most 10 characters, leading zeros preserved exactly as typed. The component reports validity only once all 10 digits are present; shorter values stay neutral while typing. If your backend stores codes without leading zeros, the [National ID](/docs/utilities/national-id) utility's `isValidNationalId` also accepts 8–9 digit values and zero-pads them internally.
