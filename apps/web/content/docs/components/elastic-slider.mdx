## Usage

```tsx
import { ElasticSlider } from "@/components/elastic-slider"

const [opacity, setOpacity] = useState(0.5)

<ElasticSlider
  label="Opacity"
  min={0}
  max={1}
  value={opacity}
  onValueChange={setOpacity}
/>
```

Uncontrolled:

```tsx
<ElasticSlider label="Opacity" min={0} max={1} defaultValue={0.5} />
```

## Range slider

Need two handles on one track — a min and a max, like a price filter? Use [Elastic Range Slider](/docs/components/elastic-range-slider) instead.
